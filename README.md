# Digital Sorcery

**Every app starts as a spell.** Digital Sorcery teaches you to start an app the right way:
gather the seven ingredients, cast them into one clear starter prompt for your AI builder,
then refine it round by round with the Iteration Ritual.

A free, installable, offline-ready web app by **Butler Builds**. No accounts. No tracking.
Your words never leave your device.

## The seven ingredients
I. The Intent · II. The Summoned · III. The Powers · IV. The Wards · V. The Tools · VI. The Laws · VII. The Proof

## Quick start (developers)
```bash
npm ci && npm start   # http://localhost:4173
npm test              # unit + browser tests
```
