## App files (what ships to the website)
| File | What it is |
|---|---|
| `index.html` | The single page and its security policy. |
| `src/app.js` | UI: renders, reacts, saves, casts, copies. |
| `src/incantation.js` | Pure logic: cleaning, scoring, counsel, casting. |
| `src/spellbook.js` | Data: the seven ingredients and the Iteration Ritual. |
| `src/storage.js` | Safe on-device storage of drafts and theme. |
| `src/portals.js` | Data: the AI apps a spell can be opened in (Portals), and the Spell Forge "coming soon" card. |
| `src/examples.js` | Data: the three example spells (picker and See Examples pop-up). |
| `src/app-tools.js` | Footer tools: Download app, Hard refresh, service worker start-up. |
| `src/styles/brand.css` | Brand tokens (colors, fonts, spacing, radius). |
| `src/styles/main.css` | Layout and components. |
| `sw.js` | Service worker (offline). |
| `manifest.webmanifest` | PWA install info (name, icons, colors). JSON: no comments possible. |
| `assets/icons/` | App icon (SVG source + PNGs). |
| `assets/fonts/` | Self-hosted brand fonts + their licenses. |

## Tooling (does not ship)
| File | What it is |
|---|---|
| `package.json` | Scripts and the one dev dependency (Playwright). JSON: no comments possible. |
| `package-lock.json` | Exact pinned dependency tree (generated by npm; don't edit by hand). |
| `.gitignore` | Files git ignores (node_modules, test results, .env files). |
| `playwright.config.js` | Browser test settings (Note 20 + small phone). |
| `tests/unit/` | Node unit tests for the logic, the Portals list, the example spells and `firebase.json` (cache headers, hosting only). |
| `tests/e2e/` | Real-browser tests, including attack inputs (`app.spec.js`) and the v1.2 features (`v1-2.spec.js`). |
| `scripts/serve.js` | Local preview server. |
| `scripts/build-site.js` | Copies only the shipping files into `_site/` (the folder both hosts publish). |
| `scripts/check-contrast.js` | WCAG contrast check of brand colors (text, hover, borders). |
| `scripts/check-invisible.js` | Fails if any tracked file contains hidden characters. |
| `scripts/make-icons.js` | Renders PNG icons from the SVG. |
| `.claude/agents/` | The five Trial by Fire stress-test agents. |
| `.github/workflows/ci-deploy.yml` | Test on every push; publish main to GitHub Pages (and Firebase Hosting, once a key is allowed: D20). |
| `firebase.json` | Firebase Hosting settings: which folder to publish, cache and security headers. JSON: no comments possible. |
| `.firebaserc` | Which Firebase project to publish to. JSON: no comments possible. |
| `.github/dependabot.yml` | Automatic dependency update PRs. |
